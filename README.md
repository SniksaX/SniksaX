## Siraj Rahal

Full-stack developer working on applied AI. I build production retrieval systems and
self-hosted inference infrastructure for organisations that can't send their data to a
third-party API  and the backend, tooling and interfaces that go with them.

### Current work

Rebuilding an internal retrieval stack end to end: three-arm hybrid search over PostgreSQL
and pgvector, RRF fusion, cross-encoder reranking, all served by self-hosted llama.cpp and
vLLM. Every change validated against a measured baseline  recall and MRR.
Alongside it, a deterministic threat scoring engine over Elasticsearch that reads the shape
of network traffic rather than its volume.

### Selected projects

- **[OpenWard](https://github.com/SniksaX/OpenWard)**  Zone-based Zero Trust Network Access on WireGuard. A Go API running on the gateway owns `wg0.conf` and regenerates it from SQLite; `iptables` enforces six access zones as a one-way mirror.
- **[cpcode](https://github.com/SniksaX/Cpcode)**  Zero-dependency Go CLI that packages a codebase into a single LLM-optimised context. Concurrent multi-core walk, token estimation, Markdown/XML output, cross-platform clipboard.
- **[AgenticAI](https://github.com/SniksaX/AgenticAI)**  Python agent that generates and validates documentation with executable examples from source.
- **[httz](https://github.com/SniksaX/httz)**  Minimal Node.js/TypeScript web framework built on the native `http` module: routing, streams, request parsing.
